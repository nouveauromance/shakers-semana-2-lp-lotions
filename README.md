# Ambiente Shopify + Liquid Inicial - Desafio Shakers Academy

## Informações do projeto:

🎇 O projeto foi desenvolvido como parte do "Desafio - Semana 2" de introdução ao ambiente Shopify e ao Liquid, proporcinado pela Shakers University
para o programa de capacitação.

---

## O que foi implementado?

- Template da landing page na pasta correspondente.
- Section com title, content, collection e schema da landing page.   
- Correções e ajustes nos conteúdos e códigos.

---

## Fluxo de desenvolvimento aplicado

1. Criação do template JSON

2. Criação da section com estrutura Liquid

3. Implementação do schema

4. Uso dos objetos page, product e collection

5. Validação no tema via Shopify CLI

6. Versionamento via Git

---

## Como testar localmente?

1. Acesse a pasta do projeto.

2. Rode o servidor local.

3. Acessar a URL exibida no terminal.

---

## Como configurar no Admin?

1. Crie uma nova página no Shopify Admin.

2. Selecione o template.

3. Acesse o Editor de Temas.

4. Na section "Lotion LP":

- Selecione o Produto principal.

- Selecione a Coleção de loções.
